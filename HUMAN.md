# Что где лежит в проекте

Проект — лабораторные работы в эмуляторе сетей PNETLab и отчёты к ним (PDF собирается из исходника
на языке [typst](https://typst.app)). У каждой лабы своя папка, все отчёты оформляются общим шаблоном.

## Корень

| Что | Зачем |
|---|---|
| `README.md` | Как установить typst и шаблон, как собрать отчёт |
| `human.md` | Этот файл: структура проекта для людей |
| `CLAUDE.md` | Инструкции для ИИ-ассистента (Claude Code): правила работы со стендом и отчётами. Людям читать не обязательно |
| `Makefile` | `make` — собрать все отчёты, `make BKS/lab1` — один, `make watch-BKS/lab1` — пересобирать при каждом сохранении |
| `new-lab.sh` | Создать папку новой лабы из заготовки: `./new-lab.sh BKS/lab2` |
| `tools/extract-configs.py` | Достать конфиги всех устройств из выгрузки PNETLab в папку `configs/` лабы |
| `mephi-labs/` | Общий шаблон оформления (титульный лист, ГОСТ 7.32, шрифты). Его правка меняет **все** отчёты сразу |
| `BKS/`, `SA/` | Лабы по предметам: `BKS/lab1`, `SA/...` (в `SA` пока пусто) |
| `.gitignore` | PDF и служебные файлы в git не попадают |

### `mephi-labs/` — шаблон

| Что | Зачем |
|---|---|
| `lib/` | Код шаблона: титульник (`title-lab.typ`), оформление и функции для листингов (`lab.typ`), логотипы и шрифт в `assets/` |
| `template/` | Заготовка, которая копируется в новую лабу (`main.typ`, пустые `img/`, `configs/`, `outputs/`) |
| `fonts/` | Times New Roman — нужен для сборки на Linux и Windows |
| `install.sh` | Установка шаблона как пакета `@local/mephi-lab` (macOS/Linux) |

## Папка лабы (на примере `BKS/lab1`)

| Что | Зачем |
|---|---|
| `main.typ` | **Исходник отчёта.** Из него собирается `main.pdf` |
| `main.pdf` | Готовый отчёт (в git не хранится, собирается заново) |
| `configs/` | Итоговые конфигурации устройств, по файлу на устройство (`DSW-1.txt` …). Идут в приложение отчёта |
| `commands/` | Команды, которые вводились на устройствах, сгруппированные по задачам (`HQ-ASW-snooping-vlans.txt` …). Из них берутся листинги «что настраивали» |
| `outputs/` | Выводы проверок: `show`, `ping`, `traceroute` (`DSW-1-ping-hq.txt` …). Из них берутся листинги «как проверяли» |
| `img/` | Картинки для отчёта: схемы, скриншоты |
| `stand/` | Готовый стенд для PNETLab (см. ниже) и `README.md` к нему: как поднять, какие адреса задать |
| `demo-checks.md` | Сценарий проверок на сдаче: какие команды где вводить и что должно получиться |
| `preamble/` | Условие лабораторной (PDF методички) |
| `tools/` | Скрипты этой лабы: `pfsense-gui.py` — выгрузить/загрузить конфиг межсетевого экрана pfSense через его веб-интерфейс, `pfsense-config.py` — собрать этот конфиг |
| `hq-plan.md` | Проект сети головного офиса: устройства, порты, адресация, принятые решения |
| `HUMAN.md` | Шпаргалка к защите: как устроена сеть, что будет при отказах, вероятные вопросы, словарь терминов |
| `CLAUDE.md` | Рабочий журнал ассистента по этой лабе: состояние стенда, что сделано и что осталось, найденные проблемы. Подробный, но черновой |

Имена файлов в `commands/` и `outputs/` — `<устройство>-<что>.txt`, так проще найти нужный вывод.

## Что такое выгрузки (`stand/pnetlab_export-*.zip`)

Это **экспорт лабы из PNETLab** — архив, в котором лежит вся лаба целиком:

- топология: устройства, связи между ними, их расположение на схеме (файл `.unl`);
- сохранённые конфигурации всех устройств (startup-config), то есть с ними сеть поднимается уже настроенной.

Зачем нужен:

- **резервная копия** — если стенд в PNETLab сломается или удалится, его можно вернуть;
- **перенос** — на другом компьютере или у другого человека: PNETLab → *Import* → выбрать zip → *Start all*;
- **база для следующих лабораторных** — следующие ЛР строятся поверх этого стенда.

В имени — дата и время выгрузки (`20261016-174530` = 16.10.2026, 17:45:30). В папке хранится одна, актуальная
выгрузка; после новых правок на стенде её снимают заново, а старую удаляют. Чего в выгрузке нет: IP-адресов на VPCS (виртуальных ПК),
их после каждого запуска нужно задать вручную, как описано в `stand/README.md`.

## Как собрать отчёт

```sh
typst compile BKS/lab1/main.typ      # или: make BKS/lab1
```

Если шаблон не установлен (например, на Windows), смотри команду сборки в `BKS/lab1/CLAUDE.md`, раздел про шаг 12.
