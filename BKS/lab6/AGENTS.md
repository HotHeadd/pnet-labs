## Итог измерений 2026-11-26

- Установлены пакеты Ubuntu 22.04 из локального набора. Настроены постоянные адреса Netplan без маршрута по умолчанию. В гостях работают FTP и SSH/SFTP.
- В `ftp.pcap` зарегистрированы 38 пакетов, в `sftp.pcap` 57. В Wireshark экспортированы 51 байт из TCP-потока 1 в режиме Raw. Исходник, две загруженные копии и восстановленный файл совпали по SHA-256. Пароль, присутствующий в исходном FTP-дампе, сменён после захвата.
- TCP 8080 у обоих методов Nmap дал `open`, `closed` при REJECT с RST и `filtered` при DROP. UDP 53 дал `open`. Для UDP 5300 подтверждены `closed` по ICMP 3/3, `filtered` по ICMP 3/13 и `open|filtered` при отсутствии ответа. Временные правила и тестовые HTTP/DNS удалены, контроль в `outputs/server-udp-cleanup.txt`.
- Проведены девять передач по SFTP по 64 МиБ. Медианы времени: 1,44 с, 3,61 с и 1,43 с для исходного режима, задержки и потерь. Все девять файлов совпали с оригиналом по SHA-256. Выводы `qdisc-before.txt` и `qdisc-after.txt` совпадают. Захват первого прогона каждого режима, скриншоты Wireshark и отчёт сохранены локально.
- После выгрузки всех результатов пропала связь с PNETLab. Повторный опрос через MCP, HTTP и SSH не прошёл. Последнее подтверждённое состояние гостевых узлов включает снятые экспериментальные ограничения. Временный DHCP без раздачи шлюза и DNS и адрес управления `192.168.106.254/24` были добавлены к мосту `vnet13_1` самого PNETLab при первичной настройке. После восстановления доступа проверить их состояние и снять эти временные настройки. Сессию 13 не закрывать.
