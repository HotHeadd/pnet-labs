# Стенд BKS6

`BKS6.zip` содержит выгрузку топологии `/BKS labs/BKS6.unl`. Для импорта нужен образ `linux-ubuntu-server-22.04`. На живом стенде гостевые диски находятся в сессии 13. Для воспроизведения после импорта используйте параметры и команды из `../commands/`.

В живой сессии адреса закреплены в Netplan. Для повторных передач на клиенте нужен ключ `~/.ssh/bks6-peer` и проверенная запись хоста сервера в `known_hosts`. Пароль FTP, использованный для записи дампа, отозван. Для новой записи задайте тестовый пароль через стандартный ввод `configure-server.sh` и синхронизируйте его в `~/.bks6-netrc` клиента.

Исходные PCAP, результаты Nmap, журналы и контрольные суммы хранятся в `../outputs/`. Полные снимки Wireshark находятся в `../img/`. В PDF показаны нужные области снимков, а схема топологии построена по выгрузке PNETLab.

## Выключение и повторный запуск — 2026-11-28

`BKS6.zip` обновлён выгрузкой от 2026-11-28. Обе ОС штатно выключены через
ACPI; отсутствие процессов QEMU подтверждено. Сессия 13, pod 7 и диски
оставлены на месте. ZIP содержит только топологию.

Для повторных проверок присоединиться к сессии 13 и запустить CLIENT (id1)
и SERVER (id2). Адреса 192.168.106.10 и 192.168.106.20 сохраняются в Netplan,
интерфейс ens3, внешнего шлюза нет. Тестовые HTTP/DNS-службы, правила
фильтрации и netem были сняты по окончании опытов: для их повторения
использовать команды отчёта. Проверки после нынешнего выключения не выполнялись.
