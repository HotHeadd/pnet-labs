# Стенд БКС3

Лаба: `/BKS labs/BKS3.unl`. Рабочая сессия **8**, владелец `vlad_pc`, pod 7.
Перед подключением сверить `tools/pnet-helper.py sessions` и присоединиться через **Join**.
Сессия оставлена открытой; все пять узлов должны работать.

Актуальная выгрузка: `pnetlab_export-20261027-154117.zip`.
Она содержит топологию `.unl`. Настроенные диски Linux находятся в рабочей сессии;
ZIP не содержит qcow2 и не заменяет публикацию образов.
Снимки настроенных qemu-узлов не публиковались: публикация выполняется отдельно
по запросу, с выключением ОС и проверкой клона согласно корневому `AGENTS.md`.
Открытие нового pod из исходных образов не восстанавливает итоговую конфигурацию;
для текущей работы использовать Join, а не создавать отдельную копию.

В HTML/telnet-консоли: `labadmin` / `Lab3-Console-2026` (учебный локальный пароль).
Пароль применяется только к консольному входу; SSH остаётся только по ключам.

SSH с PNETLab-хоста: `labadmin@192.168.15.211` и далее `.212–.215`,
ключ `/root/.ssh/id_rsa_dy`, `sudo` без пароля. Парольная аутентификация SSH отключена.
С Mac к сети управления прямого маршрута нет: использовать SSH через PNETLab-хост.
Для проверок из репозитория есть `../tools/read-output.py`, пример:

```sh
python3 BKS/lab3/tools/read-output.py - 212 'sudo vtysh -c "show ip ospf neighbor"'
```

Итоговые конфиги — `../configs/`, команды установки — `../commands/`,
подлинные текстовые протоколы SSH и tcpdump — `../outputs/`.
PSK IPsec и закрытые ключи TLS в публичные артефакты не включены.
Они сохранены на соответствующих узлах; подготовительные материалы —
`/opt/unetlab/bks3-seeds/` на PNETLab-хосте (доступ root).

Образы `linux-bks3-*` — тонкие производные базовой Ubuntu 22.04 со своими cloud-init
seed ISO. Базовый образ не изменён. Для передачи стенда другому серверу необходимы
базовый образ, производные образы и публикация итоговых дисков либо отдельное
воспроизведение настройки из `commands/` и `configs/` с новыми ключами.

Все адреса и службы восстанавливаются при перезагрузке ОС; VPCS в стенде нет.
Обычная остановка/запуск узла сохраняет диск, Wipe и закрытие сессии уничтожают
неопубликованное состояние. Старые БКС1 и БКС2 не изменены.

Сценарий защиты: `../demo-checks.md`. Архитектура и объяснения: `../HUMAN.md`.
