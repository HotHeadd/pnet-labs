# Сверка с методичкой БКС №7

Проверены страницы 17-20 и приложение 1 на страницах 24-25. Ссылки на разделы и номера иллюстраций относятся к итоговому main.pdf.

| Требование | Где выполнено и что подтверждает |
|---|---|
| Две ВМ и изолированный сегмент | Раздел 3, схема, адресная таблица, IPv4-маршруты обеих ВМ |
| Первичное обследование и ответы служб | Раздел 4, семь TCP-портов, HTTP HEAD и приветствия FTP/SSH/SMTP |
| Пять гипотез с признаками, последствиями и статусами | Раздел 5, таблица гипотез, отдельная отметка признаков по версии |
| Две находки разных классов | Раздел 6, FTP-пароль в пакетах и ответ 230. Раздел 7, DAV без авторизации |
| Условия, действия, ответы цели, полномочия | Вводная методика и подразделы обеих находок |
| Фактическое нарушение модели безопасности | Читаемый действующий тестовый FTP-пароль. Создание и чтение собственного DAV-файла |
| Исключение отказа связи | FTP 230/226, DAV 404/201/200 |
| Очистка после проверки | Удаление временного FTP-пользователя и каталога. DAV DELETE 204 и повторный GET 404 |
| Настройки и журнал | local_enable=YES, DAV On, журнал HTTP и права каталога |
| Структура приложения 1 | Название, расположение, риск, PoC, последствия и рекомендации обеих находок |
| Оценка и классификация | Описательная оценка, CWE-319 и CWE-862 |
| Область проверки и снижение риска | Подразделы обеих находок и раздел приоритетов |
| Заключение | Результаты двух подтверждённых находок и итог очистки |

Основные доказательства относятся к паролю временной FTP-учётной записи и записи собственного текстового файла в DAV. Параметры временной записи опубликованы после её удаления.

Для подтверждённых ошибок конфигурирования использована описательная оценка.

Все исходные PNG сохранены. SVG содержат исходный растр и показывают его верхнюю область без изменения текста. Содержательные снимки проверены в собранном PDF.
