# BKS7
BKS7.zip содержит топологию из двух QEMU-узлов и одного внутреннего моста. Диски ВМ и настройки гостевых ОС хранятся в сессии PNETLab. Адресация приведена в ../configs/.

## Сохранение и повторный запуск — 2026-11-28

`BKS7.zip` обновлён выгрузкой от 2026-11-28. Рабочая сессия 14, pod 7;
CLIENT id1/session24, METASPLOITABLE2 id2/session25. Для повторных проверок
присоединяться к этой сессии; импорт ZIP не восстанавливает настроенные диски.

Оба гостя штатно выключались, MCP подтвердил ноль работающих узлов.
В METASPLOITABLE2 исправлена запись /boot в /etc/fstab: /dev/sda1 заменено
на фактическое /dev/vda1. Исходник — /etc/fstab.pre-shutdown-20261128.
Прямое монтирование раздела проверено. После этого включён только
METASPLOITABLE2 для проверки загрузки. Связь с PNETLab временно пропала,
затем восстановилась: обычный вход в ОС и /dev/vda1 на /boot подтверждены.
После этого узел штатно выключен через sudo poweroff; MCP показывает
0 работающих узлов, процессов QEMU нет. Оба qcow2 прошли qemu-img check
без исправлений и ошибок. Прикладные опыты после загрузки не повторялись.

Адреса CLIENT 192.168.77.10 и METASPLOITABLE2 192.168.77.20, префикс /24,
без внешнего шлюза. Тестовая FTP-учётная запись и файл DAV после опытов
удалены; для повторения проверок создавать новые тестовые данные.
