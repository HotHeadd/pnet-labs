# Что выполнить вручную для БКС4

Проверено по официальным страницам GFI 2026-11-07.

**Обновление после коммита 68bfe11:** команда уже прошла официальную регистрацию, получила подписанный файл trial на 25 пользователей с AV/WebFilter до 06.12.2026 и импортировала его. Этапы получения номера и CAPTCHA повторять не требуется. Однако полная активация и доступность модулей пока не подтверждены: после импорта API продолжал возвращать противоречивые признаки. По указанию пользователя диагностика Kerio отложена; дополнительных ручных действий сейчас не требуется. Ниже сохранён первоначальный порядок для справки.

## 1. Получить trial Kerio Control — можно сделать сейчас

1. Открой [официальную форму trial KerioControl](https://gfi.ai/keriocontrol/free-trial/).
2. Введи свою почту, имя, фамилию и организацию. Используй реальные данные своей организации/учебного заведения.
3. Нажми **Continue**, укажи назначение использования, телефон, страну и регион. Самостоятельно ознакомься с условиями и подтверди их, если согласен. Рассылка предложений — отдельный необязательный пункт.
4. Нажми **Start my free trial**. По описанию GFI на указанную почту должны прийти ссылка на загрузку и 30-дневный лицензионный номер. Для нашего готового стенда повторно скачивать и переустанавливать Kerio не нужно.
5. Сохрани письмо и номер у себя. В чат достаточно написать «trial получен», сам номер присылать не требуется.

Если форма не выдаёт ключ, обратись в [поддержку GFI](https://support.keriocontrol.gfi.com/) с описанием учебного стенда Kerio Control 10.0.1. Факт заполнения формы ещё не означает, что лицензия выдана или принята устройством.

Источник: [GFI — Requesting a New Customer Trial License Key](https://support.keriocontrol.gfi.com/article/120609-requesting-a-new-customer-trial-license-key).

## 2. Открыть управление Kerio — после подготовки шлюза агентом

Сейчас стенд используется для работ с «Континентом». **Не включай Kerio и «Континент» одновременно**: у них совпадают адреса интерфейсов. Переключение шлюза и проверку доступности управления выполнит агент перед активацией. Не нажимай Stop/Destroy Lab в PNETLab.

После подтверждения готовности Kerio:

1. Убедись, что Tailscale подключён.
2. В PowerShell открой SSH-туннель и оставь окно работающим:

   ```powershell
   ssh -N -L 127.0.0.1:14082:10.1.99.1:4081 root@100.100.57.19
   ```

   Введи пароль root в интерактивном запросе SSH. Если порт занят старым туннелем, сначала закрой старый процесс либо используй другой локальный порт и такой же порт в URL ниже.

3. В браузере открой **https://127.0.0.1:14082/admin/**. Туннель передаёт соединение на Management-интерфейс Kerio. Самоподписанный сертификат/несовпадение имени для локального URL на этом учебном стенде ожидаемы; проверку TLS глобально не отключай.
4. Войди пользователем **Admin**. Это пароль Kerio, не пароль root и не пароль PNETLab. Сохранённый пароль Kerio находится на сервере в `/root/.bks4-kerio-admin-password`. Его можно посмотреть в отдельном своём SSH-окне; не отправляй значение в чат и не сохраняй в репозитории.

Этот маршрут управления использовался при первоначальной настройке; после включения Kerio агент повторно проверит его работоспособность. Пока Kerio выключен, веб-страница по туннелю не откроется.

## 3. Активировать полученный trial

1. В Webadmin открой **Dashboard → Configuration Assistant → Register product**. Если уже открыт мастер активации, перейди в его раздел **Licensing**.
2. Выбери **Trial** и в окне **Registered trial activation** введи полученный номер в **Enter your Trial License number**.
3. Если мастер показывает защитный код CAPTCHA, введи его самостоятельно, затем нажми **Next → Finish**.
4. Если мастер отклонил номер, сохрани текст ошибки без самого номера; не сбрасывай и не переустанавливай Kerio.

Порядок и названия кнопок приведены по [официальной инструкции регистрации trial](https://support.keriocontrol.gfi.com/article/120244-register-kerio-control-trial-version) и [открытию мастера регистрации](https://support.keriocontrol.gfi.com/article/116982-registering-the-kerio-control-product). Эта инструкция GFI общая: точное расположение элементов в установленной версии 10.0.1 ещё нужно сверить при включённом шлюзе.

## 4. Проверить результат и сообщить агенту

- В Licensing/Dashboard отображается зарегистрированная trial-лицензия, её срок и доступные компоненты.
- Проверь отдельно наличие антивируса, IPS и Web Filter/application awareness: именно их доступность нужна для испытаний лабы.
- Напиши «Kerio активирован» либо передай текст ошибки без лицензионного номера. Скриншот лицензии перед отправкой обрежь/замажь, если на нём видны номер или персональные данные.

Агент после этого проверит статус через API, обновления баз и выполнит функциональные испытания. Наличие лицензии само по себе не подтверждает работу защитных модулей. По GFI регистрация trial не продлевает уже начавшийся срок оценки.
