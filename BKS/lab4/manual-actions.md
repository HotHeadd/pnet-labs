Для полного закрытия задания остаётся один из двух путей:

1. Завершить штатную активацию с помощью GFI/поставщика легальной учебной лицензии, затем выполнить AV/IPS, пользователей/группы, контроль приложений и GeoIP на Kerio.
2. Согласовать с преподавателем конкретное эквивалентное задание для недоступных модулей и выполнить его. Методичка явно требует такого согласования (стр. 33); оно пока не подтверждено. Проверки МЭ/NAT не считаются согласованной заменой.
