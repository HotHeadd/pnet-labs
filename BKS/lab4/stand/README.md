## Что содержит архив

`.unl` содержит топологию, параметры узлов и привязку к образам. Это **не копия работающих дисков QEMU** и не доказательство публикации их конфигурации. Настройки ОС, NGFW и сервисов находятся в оверлеях существующей сессии. Публикация новых образов в этой работе не выполнялась.

Нативная зашифрованная копия ЦУС хранится вне Git на ADMIN-LINUX в `/home/labadmin/bks4-backups-private/`; сведения о проверенной копии — в `../outputs/continent-native-backup.txt`. Свежая копия после интеграции `68bfe11` проверена штатным восстановлением CDC: описание контрольного объекта вернулось, хеши правил и адресов совпали. Подробности — `../outputs/continent-native-restore.txt`. Пароли и лицензионные данные в архивы отчёта не добавлять.
