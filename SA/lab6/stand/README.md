# СА №6, вариант 6 — текущий стенд

Лаба: `/SA labs/SA6.unl`, рабочая сессия 15, pod 7, автор `vlad_pc`.
Для доступа из браузера использовать Running Labs → SA6 → Join.

Топология: `pnetlab_export-20261127.zip`. Архив содержит четыре QEMU-узла
и две сети. Гостевые диски и их текущее состояние в ZIP не входят.

|---|---|---|
| DIRECTORY | 10.60.0.10/24 | 192.168.15.231/24 |
| APPS | 10.60.0.20/24 | 192.168.15.232/24 |
| WEB | 10.60.0.30/24 | 192.168.15.233/24 |
| WORKSTATION | 10.60.0.100/24 | 192.168.15.234/24 |

Проверены загрузка ОС, cloud-init, SSH и базовая связность рабочей сети.
Установка пакетов и настройка служб ещё не завершены; точное состояние
и следующий шаг записаны в `../AGENTS.md`.

Начальная подготовка дисков и cloud-init находится в `../tools/prepare-hosts.py`.
Образы `linux-sa6-*` зависят от общего `linux-ubuntu-server-22.04`.
Не удалять общий образ и не создавать вторую запущенную копию этой лабы:
в pnet0 возникнут одинаковые MAC/IP.
