# СА №6, вариант 6 — текущий стенд

Лаба: `/SA labs/SA6.unl`, рабочая сессия 15, pod 7, автор `vlad_pc`.
Для доступа из браузера использовать Running Labs → SA6 → Join.

Топология: `pnetlab_export-20261128.zip`. Архив содержит четыре QEMU-узла
и две сети. Гостевые диски и их текущее состояние в ZIP не входят.
На исходном PNET-хосте они сохраняются в оверлеях рабочей сессии.

| Узел | Рабочий адрес | Служебный адрес |
|---|---|---|
| DIRECTORY | 10.60.0.10/24 | 192.168.15.231/24 |
| APPS | 10.60.0.20/24 | 192.168.15.232/24 |
| WEB | 10.60.0.30/24 | 192.168.15.233/24 |
| WORKSTATION | 10.60.0.100/24 | 192.168.15.234/24 |

На DIRECTORY настроены и проверены LDAPS и NFS. APPS и WORKSTATION получают
пользователей из LDAP через SSSD и используют общий NFS-каталог. Проверены
чтение/запись Alice и отказ Bob и root клиента. На APPS применены правила
SSH для групп sudo и xpra-users. С WORKSTATION проверены LDAP-пароли обоих
пользователей, успешный парольный SSH-вход Alice и отказ Bob; журнал APPS
подтвердил причину отказа AllowGroups.

На APPS работают Tryton/PostgreSQL и сеанс Xpra Alice :100. С WORKSTATION
подтверждены прикладной вход Alice, отказ Bob, публикация одного окна Tryton
и reconnect с сохранением UUID сеанса и PID приложения.

На WEB работают Keycloak, Gitea, Vaultwarden и PostgreSQL. Проверены LDAPS-
федерация Alice/Bob, HTTPS с доверенным CA и реальный браузерный SSO между
Gitea и Vaultwarden (общий sessionId в событиях Keycloak). В SA6 Team Alice
Owner, Bob User с просмотром только Shared. Проверены HTTP200 чтения Shared,
отказы чтения Private и изменения Shared; версия записи не изменилась.

Топология выгружена заново 2026-11-28 перед выключением. Настроенные QEMU-диски
не публиковались в образы. Для демонстрации использовать сохранённую сессию15,
а не новую копию ZIP. Краткий порядок: `../demo-checks.md`.

Начальная подготовка дисков и cloud-init находится в `../tools/prepare-hosts.py`.
Образы `linux-sa6-*` зависят от общего `linux-ubuntu-server-22.04`.
Не удалять общий образ и не создавать вторую запущенную копию этой лабы:
в pnet0 возникнут одинаковые MAC/IP.

## Выключение и повторный запуск — 2026-11-28

Все четыре ОС штатно выключены через systemctl poweroff, сессия 15 и
настроенные диски сохранены. Отсутствие четырёх процессов QEMU проверено.
Сначала присоединиться к прежней сессии, затем запустить DIRECTORY (id1),
дождаться LDAPS/NFS; запустить APPS (id2) и WEB (id3), затем WORKSTATION (id4).

На WORKSTATION запустить `sudo systemctl start sa6-xpra-client` либо ярлык
SA6 Tryton: этот клиент не включён в автозапуск. Браузерные входы и
разблокировку хранилища выполнить заново. PID и UUID Xpra после выключения
ОС изменятся; прежние значения относятся к сохранённым проверкам reconnect.
Проверки после повторного запуска ещё не выполнялись.
